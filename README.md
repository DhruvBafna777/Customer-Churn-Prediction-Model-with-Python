# Customer Churn Prediction
A simple machine learning project to predict customer churn using Logistic Regression.

## Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## Dataset
Telco Customer Churn dataset from Kaggle.

## Results
- Accuracy: 79.63%

## How to Run
1. Install dependencies: `pip install pandas numpy scikit-learn matplotlib seaborn`
2. Update CSV path in code.
3. Run `python churn_predictor.py`
